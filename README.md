# 호식이두마리치킨 리뉴얼 학습용 시안

브라우저에서 `index.html`을 열면 확인할 수 있습니다. `index.html`(구조), `style.css`(디자인·반응형), `script.js`(배너·탭·사이트 전환), `assets/logo.png`(제공된 로고)로 구성했습니다.

## 자료 기반 구조
- 브랜드: HERO → 대표메뉴 → APP 주문/혜택 → 매장찾기 → 이벤트
- 창업: HERO → 창업성과 → 창업정보 → 창업상담
- 레퍼런스: 설빙(브랜드/창업 분리), 교촌(앱 정보), bhc(섹션 간 여백)

## 직접 보완한 디자인
- 레드 컬러를 앱 영역에 집중 적용해 섹션의 시각적 구분을 강화했습니다.
- 지도는 실제 위치 데이터가 없는 목업 그래픽입니다.
- 앱 화면은 실제 앱 캡처가 아닌 시각적 목업입니다.
- 창업 성과 수치는 근거 자료가 없어 임의로 만들지 않았습니다.
- 이벤트는 실제 진행 중인 이벤트로 오인하지 않도록 일반 안내 카드로 구성했습니다.
- 치킨 이미지는 Unsplash의 외부 연출 사진입니다. 실제 호식이 제품 이미지가 아니므로 정식 배포 전에 공식 라이선스가 확인된 제품 사진으로 교체해야 합니다.
- 외부 사진과 웹폰트는 인터넷 연결이 필요합니다.

## 실제 연결/목업 구분
- 메뉴 상세, 메뉴 목록, 주문 안내 링크는 공식 사이트로 연결됩니다.
- 매장찾기와 창업문의 버튼은 확인되지 않은 세부 URL 대신 공식 홈페이지로 연결됩니다.
- 지도, 앱 휴대전화 UI, 이벤트 카드 및 창업 성과 카드 내용은 시안입니다.
